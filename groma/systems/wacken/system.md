Festival attendees rate bands, review a shared schedule, record personal post-show ratings, and retain archived festival history. Admin workflows import lineup CSVs and review band links and metadata. The installed Android process runs UI, use cases, domain rules, adapters, and an on-device Room cache; Supabase supplies authentication and shared data.
