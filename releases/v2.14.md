# Wacken Planner 2026 V2.14

## Scope

V2.14 is an official non-debug Android release APK for the approved standard
offline-first sync boundary.

Changes:

- Schedule-lock schema-cache failures no longer leak PostgREST table/schema
  details into the schedule UI.
- Added a Flyway schema-cache refresh migration for PostgREST.
- Manual group schedule locks are stored locally in Room first.
- Offline schedule-lock selections and clears are queued as pending operations
  and synced with Supabase when available.
- Manual sync, lifecycle sync, and sync-and-exit now include schedule-lock sync.
- Added ADR 0010 for the offline-first sync boundary.

## Signing

V2.14 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

## Install / Upgrade Guidance

V2.14 should install over V2.9 and later APKs signed with the same stable local
release key. Devices still running V2.8 or older releases signed with the
missing temporary key must uninstall once, install V2.14, sign in, and sync from
Supabase.

## Known Non-Goals

- No Play Store distribution in V2.14.
- No rich multi-user conflict resolution UI for offline lock conflicts.
- No backend migration execution from this machine when the Supabase database
  host is unreachable; V007/V008 must still be applied from a reachable
  database connection for remote schedule-lock sync to work.

## Accepted Risks

- Local pending schedule-lock operations win over remote pulls on the same
  conflict key until they sync.
- Supabase still resolves concurrent synced group lock changes with
  last-write-wins upsert/delete semantics.
- Fresh devices without cached festival data still need one successful sync or
  import before offline use.
