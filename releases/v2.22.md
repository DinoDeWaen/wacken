# Wacken Planner 2026 V2.22

## Scope

V2.22 is the official signed Android hotfix release for the Settings crash found
after V2.21.

Changes since V2.21:

- Fixed a deterministic crash when opening Settings. The rating allocation
  `TextView` is now initialized before it is styled and added to the Settings
  screen.
- Added regression coverage for the Settings initialization order that caused
  the crash.

## Signing And Installation

V2.22 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

Install it over a release that uses the same stable signing key. Devices still
using an APK signed before the stable key was introduced must uninstall the old
app once, install V2.22, and then sync from Supabase. Future releases signed by
this key will update normally.

## Known Non-Goals

- No new MVP4 capability is part of this hotfix.
- No Play Store distribution in V2.22.
- No database, sync, auth, or architecture changes are part of this hotfix.

## Accepted Risks

- Physical Settings smoke testing was not executed from this workspace. The
  hotfix uses focused regression coverage, Android compile/build validation, and
  signed APK verification.
- Devices still using an APK signed before the stable key was introduced must
  uninstall once before installing V2.22.
