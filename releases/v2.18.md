# Wacken Planner 2026 V2.18

## Scope

V2.18 is a signed local release APK for the band biography HTML cleanup defect.

Changes:

- Band detail biographies are rendered as readable text even when source data
  contains HTML tags.
- Common HTML entities such as non-breaking spaces, ampersands, quotes, and
  numeric entities are decoded for display.
- Meaningful paragraph and line-break spacing is preserved where practical.
