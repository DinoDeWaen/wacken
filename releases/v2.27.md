# Wacken Planner 2026 V2.27

## Scope

V2.27 is the official signed Android hotfix release for the crash that occurs
after the app shows `Loading bands...`.

Changes since V2.26:

- Bumps the local Room cache schema from version 7 to version 8.
- Removes the undeclared `idx_festivals_one_active` index from the festival
  migration path.
- Adds a `7 -> 8` Room migration that drops `idx_festivals_one_active` for
  devices that already created it.
- Updates migration regression coverage so the local database schema matches the
  Room entity model during startup validation.

## Signing And Installation

V2.27 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

Install it over a release that uses the same stable signing key. Devices still
using an APK signed before the stable key was introduced must uninstall the old
app once, install V2.27, and then sync from Supabase. Future releases signed by
this key will update normally.

## Known Non-Goals

- No editable archived festivals in V2.27.
- No fuzzy band linking or alias storage in V2.27.
- No Play Store distribution in V2.27.
- No Supabase schema change is part of this hotfix.

## Accepted Risks

- Emulator logcat could not be captured from this workspace because ADB
  repeatedly returned `waiting for device` and protocol faults.
- This release changes only the local Room cache schema. It does not alter
  Supabase production data.
- Devices still using an APK signed before the stable key was introduced must
  uninstall once before installing V2.27.
