# Wacken Planner 2026 V1.0

Release date: 2026-06-04

## Scope

V1.0 is the MVP1 Android debug APK release for Wacken Planner 2026. It supports:

- Supabase Auth email/password sign-in for the shared Wacken planning group.
- Supabase-backed master-data sync into the local Room cache.
- Android CSV import for bands, stages, performances, stage distances, and food options.
- Band overview with rating, stage, date, time, YouTube, and Spotify actions.
- Band detail screen with schedule data, music links, image/biography metadata where available, and visible 1-5 rating stars.
- Local-first rating saves with persistence after app restart and pending sync support.
- Invalid CSV import feedback that preserves existing imported data and ratings.

## Known Non-Goals

- No Play Store distribution in V1.0.
- No multiple independent groups in the current version.
- No MVP2 schedule decision engine, conflict resolution, or timeline generation yet.
- No MVP3 travel feasibility, lunch planning, or food suggestions yet.
- No MVP4 PDF schedule export yet.

## Accepted Risks

- The repository UAT checklist still contains an older empty-state expectation from before Supabase Auth became mandatory. The V1.0 app now requires sign-in and syncs central master data after authentication.
- V1.0 is a debug APK release intended for local installation and validation, not a production store release.
- A disposable Supabase UAT user was created during release validation.
