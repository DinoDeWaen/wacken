# Wacken Planner 2026 V2.33

## Scope

V2.33 is an official signed Android APK with three fixes to the existing
festival planning flows:

- Opening a missing band detail no longer creates a placeholder band in the
  shared catalog or Room cache. Known band detail and rating actions remain.
- Android festival CSV imports now retain quoted commas, doubled quotes, and
  embedded line breaks. Malformed quoting reports the file and row before
  changing master data.
- The five-file Android TSV fallback import saves recoverable copies of its
  source files and replaces all five Room cache tables in one transaction. A
  reported persistence failure rolls Room back and restores the TSV files;
  existing ratings are outside the replacement.

The backend admin importer, Supabase schema, schedule rules, and Play Store
distribution did not change.

## Signing And Installation

This APK uses the stable local V2.9+ release key at the gitignored path managed
by `scripts/ensure-release-keystore.sh`. It updates an installation signed by
that same key. Devices still using an APK signed with the earlier lost key must
uninstall once, install V2.33, sign in, and sync from Supabase. Uninstalling can
remove local-only data, so export ratings before that change when needed.

Download `app-release.apk` from this GitHub release, allow installation from
the chosen source on Android, and open the installed app. This is a direct
install release, not a Play Store package.

## Build And Validation

The release was built with JDK 21 and the existing keystore and passwords
read from the local macOS Keychain:

```bash
ANDROID_HOME=/Users/dino/Library/Android/sdk \
JAVA_HOME=$(/usr/libexec/java_home -v 21) \
WACKEN_RELEASE_STORE_FILE=$(security find-generic-password -s WACKEN_RELEASE_STORE_FILE -w) \
WACKEN_RELEASE_STORE_PASSWORD=$(security find-generic-password -s WACKEN_RELEASE_STORE_PASSWORD -w) \
WACKEN_RELEASE_KEY_ALIAS=$(security find-generic-password -s WACKEN_RELEASE_KEY_ALIAS -w) \
WACKEN_RELEASE_KEY_PASSWORD=$(security find-generic-password -s WACKEN_RELEASE_KEY_PASSWORD -w) \
./gradlew clean :domain:test :application:test :infrastructure:test \
  :app:testDebugUnitTest :app:compileDebugJavaWithJavac \
  :app:lintVitalRelease assembleRelease --no-daemon
```

The APK is checked with `apksigner verify --verbose`, `aapt dump badging`,
`shasum -a 256`, and `git diff --check`. Release lintVital and the full unit
suite also pass.

## Known Risks And Non-Goals

- Recovery after an app process or device power loss during the five-file import
  is outside this release. If TSV restoration itself fails, the app reports the
  retained backup location for manual recovery.
- A physical-device import walkthrough was not run for these fixes. JVM tests
  cover the application and adapter behavior; Android Activity wiring has
  source-level regression coverage.
- Full `lintDebug` still reports 14 pre-existing `NewApi` findings in untouched
  files. Release `lintVital` passes.
- The app is not distributed through Google Play. This release does not rotate
  the signing key or add a general offline conflict engine.
