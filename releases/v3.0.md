# Wacken Planner 3.0

Paired Ironline dark and Field Notes light presentation across the existing
Android app, with labeled navigation, accessible scoped rating controls and
retained screen context. The existing canonical rating lifecycle is preserved.

## Changes

- Settings → Appearance offers System, Dark and Light. An installation without
  a valid preference defaults to System and follows device appearance. Explicit
  choices stay on this device. The header switch selects the opposite explicit
  appearance; return to System through Settings.
- Bands, Schedule and Settings have visible destination labels and selected
  state. Narrow screens with enlarged text stack those actions. Detail/review
  Back returns to its caller without discarding the existing context.
- Wrapping lineup facts, search/filter state, native 48dp rating choices and
  explicit festival planning versus After the show controls improve readability.
  Established personal opinion and archived history remain separate.
- Schedule filters, calendar facts, decision alternatives and explicit shared
  locks use both palettes, readable text and retained selection/viewport. The
  calendar keeps necessary horizontal scrolling.
- Settings, identity/music/metadata evidence review, import, login, archived
  lists and confirmations use coherent native styling and safe draft/recovery
  state. Restyling/recreation never approves or resubmits a business operation.
- Android 15+ content respects system bars, cutouts and the keyboard. Exposed
  safe areas follow the selected palette. No backend preference sync, provider,
  database migration or rating/scheduling policy change is introduced.

## Validation and limits

TASK-212 records 44 actual Android captures with source/device/APK hashes,
normal and 320×480dp layouts at 200% text, real installed TalkBack focus/role/value
checks, keyboard Tab/Enter and reachable 48dp controls. Both palettes pass the
complete 99-case native suite; API 23/API 36 CI each passes 99 cases. Independent
specified-color contrast minima exceed 4.5:1 for text and 3:1 for meaningful
boundaries. See the [native validation record](https://github.com/DinoDeWaen/wacken/blob/v3.0/backlog/docs/release-3.0-native-validation-2026-10-23.md).

The release gates additionally require final-source JVM/BDD/QA/coverage/ArchUnit,
lint, repeatable reviewed Groma, disposable real database/API and native CI,
plus the exact published 2.35.1/code44 →3.0/code45 signed upgrade. The probe checks
retained login/private cache, festivals/canonical metadata, own/other ratings,
planning/after values, dated history, correction audit and pending operations,
normal offline launch and default System appearance. Publication evidence records
the final outcomes; environment-gated JVM integration skips are separate from
mandatory real integration passes.

User review approved the paired prototype on 17 October 2026. Actual TalkBack
automation and agent screenshot inspection are not a human spoken-feedback study.
No physical Switch Access, bright-sun, glove, wet-screen or one-handed test was
performed. These remain explicit limits; there is no outdoor usability or full
accessibility-certification claim. Native dialogs/system pickers and other apps
retain their Android/target-app behavior. Known source-scanner limitations and the
two previously accepted stale importer arrows remain documented.

## Install or update

Download the official `app-release.apk`, compare its digest with `SHA256SUMS`,
open it on Android and choose Update over the stable-key installation. Do not
uninstall the working app to update: a compatible signed update retains local
data. Installation permission may be needed for the browser/file manager. Open
the app and check cached festivals/ratings, then confirm sync before relying on
shared acknowledgement. Protect pending edits until sync is confirmed.

This remains manual signed GitHub APK distribution. Android normally blocks
downgrades; prefer a higher-code corrective release. The historical lost-key
reinstall exception remains separate. No replacement key, store distribution,
automatic updater or additional group/festival policy is introduced.
