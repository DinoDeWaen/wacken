# Wacken Planner 2026 V2.26

## Scope

V2.26 is the official signed Android hotfix release for the remaining crash
after V2.25, where the app could render the main Wacken band list and then stop
while archive/start-state or archived festival data paths were evaluated.

Changes since V2.25:

- Removes all remaining direct `Stream.toList()` calls from production
  Android-reachable code paths.
- Fixes archive/start-state, archived festival list, archived band detail,
  export, and import paths to use Android-compatible collection APIs.
- Adds a production-source regression test that fails if direct
  `Stream.toList()` is reintroduced in app, application, domain, or
  infrastructure production Java code.

## Signing And Installation

V2.26 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

Install it over a release that uses the same stable signing key. Devices still
using an APK signed before the stable key was introduced must uninstall the old
app once, install V2.26, and then sync from Supabase. Future releases signed by
this key will update normally.

## Known Non-Goals

- No editable archived festivals in V2.26.
- No fuzzy band linking or alias storage in V2.26.
- No Play Store distribution in V2.26.
- No new Supabase table or database schema version is part of this hotfix.

## Accepted Risks

- Emulator logcat could not be captured from this workspace because ADB
  repeatedly returned `waiting for device` and protocol faults. The fix is based
  on the observed timing, code inspection, a comprehensive production-source
  compatibility scan, focused regression tests, and full release validation.
- Devices still using an APK signed before the stable key was introduced must
  uninstall once before installing V2.26.
