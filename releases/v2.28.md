# Wacken Planner 2026 V2.28

## Scope

V2.28 is the official signed Android hotfix release for Supabase personal
rating sync failing on offset timestamps.

Changes since V2.27:

- Parses Supabase `personal_band_rating_events.created_at` values in both
  instant `Z` format and offset format such as
  `1970-01-01T00:00:00+00:00`.
- Normalizes accepted Supabase timestamp formats to `Instant` before saving to
  the local cache.
- Adds regression coverage for both timestamp formats.

## Signing And Installation

V2.28 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

Install it over a release that uses the same stable signing key. Devices still
using an APK signed before the stable key was introduced must uninstall the old
app once, install V2.28, and then sync from Supabase. Future releases signed by
this key will update normally.

## Known Non-Goals

- No editable archived festivals in V2.28.
- No fuzzy band linking or alias storage in V2.28.
- No Play Store distribution in V2.28.
- No Supabase schema change is part of this hotfix.

## Accepted Risks

- This release fixes the known Supabase timestamp parse failure shown by the app
  message. It does not change Supabase data.
- Devices still using an APK signed before the stable key was introduced must
  uninstall once before installing V2.28.
