# Wacken Planner 2026 V2.0

Release date: 2026-06-07

## Scope

V2.0 is the MVP2 Android debug APK release for one shared Wacken planning
group. It includes all V1.1 capabilities plus:

- Single-group decision rules for shared ratings.
- Conflict detection for overlapping performances.
- Conflict resolution using must-see ratings, want-to-see counts, vetoes, and distance tie-breakers.
- Shared day timeline generation with selected performances, schedule status, and lost alternatives.
- Android schedule screen for viewing the generated MVP2 group schedule, including winner stars and lost-alternative stars.
- Existing Supabase user backfill into the canonical `Sofie and Dino` group.
- Rating clear action that returns a band to unrated and removes the explicit Supabase rating contribution after sync.
- Return from band detail to the selected overview row after refresh.
- Android share-sheet invite instructions for the single shared group.
- Android runtime compatibility fix for the group schedule screen on devices that do not provide newer Java collection/optional APIs.

## Package Updates

The `v2.0` GitHub release asset has been replaced with rebuilt debug APKs after
MVP2 validation defects were fixed:

- Rebuilt after the Android runtime compatibility fix for the group schedule screen.
- Rebuilt after adding visible winner and lost-alternative stars to the schedule.

## Known Non-Goals

- No Play Store distribution in V2.0.
- No multiple independent groups in the current version.
- No self-service invite-token lifecycle or deep-link join flow.
- No MVP3 user-configurable travel/lunch/food behavior.
- No MVP4 PDF export.

## Accepted Risks

- V2.0 is a debug APK release intended for local installation and validation,
  not a production store release.
- Installed-device UAT could not be executed in this Codex environment because
  `adb devices` reported no connected devices or emulators. Use the MVP2 UAT
  checklist for device validation after installing the APK. This gap is accepted
  for closing the MVP2 debug APK release task because the release asset now
  includes the follow-up Android runtime crash fix and visible schedule-star
  validation.
- The MVP2 invite action uses safe plain-text onboarding for provisioned
  accounts; it is not a self-service registration or invite-token flow.
