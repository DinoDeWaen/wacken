# Wacken Planner 2026 V2.24

## Scope

V2.24 is the official signed Android hotfix release for archived Wacken
real-rating recovery when legacy local rating data was stored under an older
local identity.

Changes since V2.23:

- Recovers positive legacy Wacken `real_ratings` rows for the currently
  signed-in user when the current user has no archived Wacken personal rating
  history yet.
- Stores restored legacy personal rating events with deterministic
  UUID-compatible ids, so they can sync to Supabase
  `personal_band_rating_events`.
- Removes stale local colon-based legacy event duplicates when replacing them
  with UUID-compatible restored events.
- Keeps old pending non-UUID personal rating event ids sync-compatible by
  mapping them to deterministic UUIDs during Supabase push.

## Signing And Installation

V2.24 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

Install it over a release that uses the same stable signing key. Devices still
using an APK signed before the stable key was introduced must uninstall the old
app once, install V2.24, and then sync from Supabase. Future releases signed by
this key will update normally.

## Known Non-Goals

- No editable archived festivals in V2.24.
- No fuzzy band linking or alias storage in V2.24.
- No Play Store distribution in V2.24.
- No new Supabase table or database schema version is part of this hotfix.

## Accepted Risks

- Physical archived-festival smoke testing was not executed from this workspace.
  The hotfix uses focused regression coverage, Android compile/build
  validation, and signed APK verification.
- The recovery intentionally assumes positive local legacy `real_ratings` rows
  on this device belong to the current signed-in user when that user has no
  Wacken personal rating history yet. That matches the old local-only real
  rating model and the one-friend-group scope.
- Devices still using an APK signed before the stable key was introduced must
  uninstall once before installing V2.24.
