# Wacken Planner 2026 V2.10

Release date: 2026-06-12

## Scope

V2.10 is the official non-debug Android release APK for the stage-column
schedule readability and walking-time refinements. It includes all V2.9
capabilities plus:

- Schedule time-axis labels now show only full hours on the left axis.
- Hour guide lines and half-hour dotted guide lines span all stage columns.
- Schedule performance blocks keep the compact `HH:mm-HH:mm` range inside the
  block and no longer repeat the stage name, because the stage is represented
  by the column header.
- Lost alternatives in schedule blocks render as smaller secondary text.
- Default walking times now treat Harder, Faster, and Louder as one 5-minute
  walking group.
- Default walking times now treat Headbangers Stage and W:E:T/WET Stage as one
  5-minute walking group.
- Travel between those walking groups or to other stages defaults to 15
  minutes unless both acts are on the same stage.

## Signing

The V2.10 GitHub release asset is built from the Android `release` variant and
signed with the same local self-signed V2.9 release-key line documented in
`backlog/docs/release-process.md`. The keystore and passwords are not committed
to git. Release signing is configured through local Gradle properties,
environment variables, or the local macOS keychain entries:

```text
WACKEN_RELEASE_STORE_FILE
WACKEN_RELEASE_STORE_PASSWORD
WACKEN_RELEASE_KEY_ALIAS
WACKEN_RELEASE_KEY_PASSWORD
```

This release is suitable for direct local installation/testing. It is not a
Play Store release and does not establish Play App Signing custody.

The APK supports Android 6.0+ (`minSdk 23`) with Java time desugaring enabled
for older emulator images.

Important upgrade note: V2.10 uses the same local V2.9 release-key line, so it
can install over V2.9. Android cannot install V2.10 over V2.8 or older releases
signed with a different certificate, or over debug builds. In that case,
uninstall Wacken Planner first, then install the V2.10 release APK and sync from
Supabase.

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew :domain:test :application:test :infrastructure:test :app:testDebugUnitTest :app:compileDebugJavaWithJavac assembleRelease
```

## Known Non-Goals

- No Play Store distribution in V2.10.
- No shared synced manual schedule choices in V2.10; manual selections are
  local visible overrides only.
- No multiple independent groups in the current version.
- No self-service invite-token lifecycle or deep-link join flow.
- No user-configurable travel/lunch/food behavior.
- No PDF export.

## Accepted Risks

- Installed-device UAT still needs to be run on a connected Android device or
  emulator using the MVP2 UAT checklist.
- The V2.10 APK is signed with a local self-signed release key for direct
  installation/testing, not with Play App Signing.
- Installing over V2.8 or any older release/debug APK may fail by Android
  design due to signing-certificate mismatch. Uninstall the previous app first.
- BlueStacks must run an Android 6.0+ image for this APK.
