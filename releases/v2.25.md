# Wacken Planner 2026 V2.25

## Scope

V2.25 is the official signed Android hotfix release for the v2.24 startup
regression in archived real-rating recovery.

Changes since V2.24:

- Makes the legacy real-rating recovery path Android-runtime-safe during app
  repository initialization.
- Avoids constructing Supabase syncing repositories when no valid local session
  is available, so startup can continue to the existing login/offline handling.
- Adds regression coverage that the personal real-rating sync path only pulls
  and upserts `personal_band_rating_events`; it does not delete remote personal
  rating history.
- Confirms the current production `personal_band_rating_events` table is empty;
  Airbourne still exists in Supabase planning/group rating tables as rating 3,
  which is separate from the real post-show rating.

## Signing And Installation

V2.25 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

Install it over a release that uses the same stable signing key. Devices still
using an APK signed before the stable key was introduced must uninstall the old
app once, install V2.25, and then sync from Supabase. Future releases signed by
this key will update normally.

## Known Non-Goals

- No editable archived festivals in V2.25.
- No fuzzy band linking or alias storage in V2.25.
- No Play Store distribution in V2.25.
- No new Supabase table or database schema version is part of this hotfix.

## Accepted Risks

- Emulator logcat became unreliable during diagnosis, repeatedly reporting
  `waiting for device`; the fix is based on code inspection, database
  validation, focused regression tests, and full release validation.
- The production Supabase table does not contain historical real-rating rows to
  restore from. The hotfix therefore protects local legacy recovery and future
  sync, but it cannot recover real ratings from an empty remote table.
- Devices still using an APK signed before the stable key was introduced must
  uninstall once before installing V2.25.
