# Wacken Planner 2026 V2.20

## Scope

V2.20 is the official signed Android release for the completed MVP2 scope.

Changes since V2.19:

- MVP2 business requirements now describe only the active MVP1 and MVP2 scope.
- The canonical business-requirements path is normalized to
  `backlog/docs/business-requirements.md`.
- Supabase group schedule locks were validated end to end: Flyway migrations
  V007 and V008 are applied to the active backend, and PostgREST can see
  `group_schedule_locks`.
- Shared schedule locks, offline pending schedule choices, schedule warning
  fallback, group ratings detail, and schedule display behavior were covered by
  the release validation package.

## Signing And Installation

V2.20 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

Install it over a release that uses the same stable signing key. Devices still
using an APK signed before the stable key was introduced must uninstall the old
app once, install V2.20, and then sync from Supabase. Future releases signed by
this key will update normally.

## Known Non-Goals

- No Play Store distribution in V2.20.
- No MVP3/MVP4 capabilities are part of this release.
- No multiple-group support is part of this release.

## Accepted Risks

- Physical two-device UAT was not directly run from this workspace. The release
  uses automated sync/offline coverage, live Supabase backend validation, and
  user-reported installed-app behavior for final MVP2 confidence.
