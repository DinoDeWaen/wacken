# Wacken Planner 2026 V1.1

Release date: 2026-06-07

## Scope

V1.1 is the MVP1 Android debug APK release that fixes cross-device rating
visibility by syncing automatically during normal app use. It includes all V1.0
MVP1 capabilities plus:

- Supabase master-data and group-rating sync when the signed-in overview starts.
- Supabase sync whenever the band overview is reactivated after returning from
  another app, the detail screen, or the import screen.
- **Sync & close** action that runs Supabase sync before closing the app.
- Full-screen Wacken/metal sync overlay with animated steel-ring feedback during
  startup, reactivation, manual sync, and close sync.
- Clear stale-data failure message while preserving local cached data and
  pending ratings when sync fails.

## APK

Debug APK artifact:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Build command:

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew assembleDebug
```

Android version metadata:

```text
versionCode 2
versionName 1.1
```

## Validation

Automated validation for V1.1:

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew :app:testDebugUnitTest
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew :app:compileDebugJavaWithJavac
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew assembleDebug
git diff --check
```

Manual validation checklist for installed devices:

- Sign in and confirm the WACKEN SYNC overlay appears before the overview is
  presented as current.
- Change a rating, return to the overview, and confirm sync runs again.
- Install/sign in on a second Android device with the same user and confirm
  synced ratings become visible after startup/reactivation sync.
- Tap **Sync & close** and confirm sync feedback appears before the app closes.
- Simulate a sync failure and confirm cached data remains visible and manual
  retry remains available.

## Known Non-Goals

- No Play Store distribution in V1.1.
- No scheduled background sync, push notifications, or WorkManager sync.
- No multiple independent groups in the current version.
- No MVP2 schedule decision engine, conflict resolution, or timeline generation
  yet.

## Accepted Risks

- V1.1 intentionally syncs on every overview activation. If Supabase usage
  becomes too chatty in practice, a later task can add throttling or a background
  sync policy.
- V1.1 is a debug APK release intended for local installation and validation,
  not a production store release.
- Device-level manual validation is documented above but was not required for
  producing the debug APK artifact.
