# Wacken Planner 2026 V2.9

Release date: 2026-06-12

## Scope

V2.9 is the official non-debug Android release APK for the Sofie and Dino
group schedule selection fix. It includes all V2.8 capabilities plus:

- Group schedule generation no longer drops rated non-overlapping acts from a
  chained conflict set.
- Schedule conflict detection and alternatives now use each act's middle
  30-minute window to decide whether two acts overlap.
- Def Leppard and other rated acts can be selected when their performance
  exists and their middle 30-minute window does not conflict with the selected
  earlier act.
- Schedule details use the same middle-30-minute overlap rule as the generated
  schedule, so alternatives stay aligned with the selected slot.

## Signing

The V2.9 GitHub release asset is built from the Android `release` variant and
signed with a newly generated local self-signed V2.9 release key. The previous
V2.5 release key file was still present locally, but its passwords were not
available in the release shell, so V2.9 starts a new local release-key line.
The keystore and passwords are not committed to git. Release signing is
configured through local Gradle properties, environment variables, or the local
macOS keychain entries documented in `backlog/docs/release-process.md`:

```text
WACKEN_RELEASE_STORE_FILE
WACKEN_RELEASE_STORE_PASSWORD
WACKEN_RELEASE_KEY_ALIAS
WACKEN_RELEASE_KEY_PASSWORD
```

This release is suitable for direct local installation/testing. It is not a
Play Store release and does not establish Play App Signing custody.

The APK supports Android 6.0+ (`minSdk 23`) with Java time desugaring enabled
for older emulator images.

Important upgrade note: Android cannot install V2.9 over V2.8 or any older
build with the same package name because V2.9 uses a new signing certificate.
If any previous Wacken Planner build is installed on BlueStacks or a device,
uninstall Wacken Planner first, then install the V2.9 release APK and sync from
Supabase.

## Known Non-Goals

- No Play Store distribution in V2.9.
- No shared synced manual schedule choices in V2.9; manual selections are local
  visible overrides only.
- No multiple independent groups in the current version.
- No self-service invite-token lifecycle or deep-link join flow.
- No user-configurable travel/lunch/food behavior.
- No PDF export.

## Accepted Risks

- Installed-device UAT still needs to be run on a connected Android device or
  emulator using the MVP2 UAT checklist.
- The V2.9 APK is signed with a new local self-signed V2.9 release key for
  direct installation/testing, not with Play App Signing.
- Installing over V2.8 or any older release/debug APK fails by Android design
  due to signing-certificate mismatch. Uninstall the previous app first.
- BlueStacks must run an Android 6.0+ image for this APK.
- If live Supabase master data lacks a performance row for a rated band, such
  as Def Leppard, the app still cannot schedule that band until master data is
  corrected.
