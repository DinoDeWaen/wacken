# Wacken Planner 2026 V2.1

Release date: 2026-06-10

## Scope

V2.1 is the official non-debug Android release APK for the MVP2 schedule UI
update. It includes all V2.0 capabilities plus:

- Compact overview navigation with settings, calendar schedule, and sync-exit icons.
- Settings screen containing group invite, lineup CSV import, and manual Supabase sync.
- Calendar-style group schedule with festival days, hour lines, and time-positioned performance blocks.
- Schedule blocks showing band, stage, and rating stars.
- Tappable schedule blocks with chosen act and alternatives.
- Local manual alternative selection that updates the visible schedule result and marks manual choices.

## APK

Release APK artifact:

```text
app/build/outputs/apk/release/app-release.apk
```

Build command:

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew assembleRelease
```

Android version metadata:

```text
versionCode 4
versionName 2.1
minSdk 23
```

## Signing

The V2.1 GitHub release asset is built from the Android `release` variant and
signed with a locally generated self-signed release keystore. The keystore and
passwords are not committed to git. Release signing is configured through local
Gradle properties or environment variables:

```text
WACKEN_RELEASE_STORE_FILE
WACKEN_RELEASE_STORE_PASSWORD
WACKEN_RELEASE_KEY_ALIAS
WACKEN_RELEASE_KEY_PASSWORD
```

This release is suitable for direct local installation/testing. It is not a
Play Store release and does not establish Play App Signing custody.

The APK supports Android 6.0+ (`minSdk 23`) with Java time desugaring enabled
for older emulator images.

Important upgrade note: Android cannot install this official release APK over a
previous debug APK with the same package name, because the signing certificates
do not match. If a V2.0 debug build is already installed on BlueStacks or a
device, uninstall Wacken Planner first, then install the V2.1 release APK and
sync from Supabase.

## Validation

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew :domain:test :application:test :infrastructure:test :app:testDebugUnitTest :app:compileDebugJavaWithJavac assembleRelease
apksigner verify --verbose app/build/outputs/apk/release/app-release.apk
git diff --check
```

## Known Non-Goals

- No Play Store distribution in V2.1.
- No shared synced manual schedule choices in V2.1; manual selections are local visible overrides only.
- No multiple independent groups in the current version.
- No self-service invite-token lifecycle or deep-link join flow.
- No MVP3 user-configurable travel/lunch/food behavior.
- No MVP4 PDF export.

## Accepted Risks

- Installed-device UAT still needs to be run on a connected Android device or
  emulator using the MVP2 UAT checklist.
- The V2.1 APK is signed with a local self-signed release key for direct
  installation/testing, not with Play App Signing.
- Installing over a previously installed debug APK fails by Android design due
  to signing-certificate mismatch. Uninstall the debug app first.
- BlueStacks must run an Android 6.0+ image for this APK.
