# Wacken Planner 2026 V2.23

## Scope

V2.23 is the official signed Android hotfix release for archived festival
browsing and Wacken real-rating preservation.

Changes since V2.22:

- Archived festivals now open with the active festival band-list layout,
  including planning stars, music-link actions, stage, date, and time columns.
- Archived band detail now uses the active-style sections for image, Your
  Rating, Real Rating, Personal History, Running Order, Band Links, and
  biography while keeping rating/reset controls read-only.
- Legacy Wacken real ratings are restored into personal rating history with an
  honest unknown-date fallback, so Airbourne-style 4-star real ratings remain
  visible after archiving and can sync through the existing personal-history
  sync path.

## Signing And Installation

V2.23 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

Install it over a release that uses the same stable signing key. Devices still
using an APK signed before the stable key was introduced must uninstall the old
app once, install V2.23, and then sync from Supabase. Future releases signed by
this key will update normally.

## Known Non-Goals

- No editable archived festivals in V2.23.
- No fuzzy band linking or alias storage in V2.23.
- No Play Store distribution in V2.23.
- No new Supabase table or database schema version is part of this hotfix.

## Accepted Risks

- Physical archived-festival smoke testing was not executed from this workspace.
  The hotfix uses focused regression coverage, Android compile/build
  validation, and signed APK verification.
- Devices still using an APK signed before the stable key was introduced must
  uninstall once before installing V2.23.
