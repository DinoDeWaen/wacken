# Wacken Planner 2026 V2.13

## Scope

V2.13 is an official non-debug Android release APK for cached-first lifecycle
sync. The band overview now renders locally cached Room data before Supabase
start/reactivation sync completes, then refreshes from Supabase in the
background. Sync-and-exit still syncs before closing.

## APK

```text
app/build/outputs/apk/release/app-release.apk
```

## Signing

V2.13 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

## Install / Upgrade Guidance

V2.13 should install over V2.9 and later APKs signed with the same stable local
release key. Devices still running V2.8 or older releases signed with the
missing temporary key must uninstall once, install V2.13, sign in, and sync from
Supabase.

## Known Non-Goals

- No Play Store distribution in V2.13.
- No full offline-write conflict policy in V2.13; the broader offline-first
  sync design remains tracked separately.
- No backend migration execution in V2.13; the `group_schedule_locks` Supabase
  schema verification remains tracked separately.

## Accepted Risks

- Supabase lifecycle sync can still fail while offline, but cached data remains
  visible and usable.
- Fresh devices without cached festival data still need an initial successful
  sync or import before offline use.
