# Wacken Planner 2026 V2.12

Release date: 2026-06-15

## Scope

V2.12 is the official non-debug Android release APK for schedule detail and
filtering corrections. It includes all V2.11 capabilities plus:

- Restored tied alternatives in schedule decision details with the
  `⚖ TIED ALTERNATIVE` marker.
- Restored visible lost alternatives for chained conflict sets where the
  resolver runner-up does not directly overlap the selected act.
- Applied the agreed rating color scheme to schedule blocks:
  5-star gold, 4-star metal red, and 2-3-star steel grey.
- Added a local `Hide barred` schedule toggle that hides scratched/barred
  overlapping acts without changing ratings or generated decisions.
- Added local inclusive star-threshold filters (`Off`, `1★`, `2★`, `3★`,
  `4★`) so the user can hide acts rated at or below a selected threshold.

## Signing

The V2.12 GitHub release asset is built from the Android `release` variant and
signed with the same local self-signed V2.9 release-key line documented in
`backlog/docs/release-process.md`. The keystore and passwords are not committed
to git. Release signing is configured through local Gradle properties,
environment variables, or the local macOS keychain entries:

```text
WACKEN_RELEASE_STORE_FILE
WACKEN_RELEASE_STORE_PASSWORD
WACKEN_RELEASE_KEY_ALIAS
WACKEN_RELEASE_KEY_PASSWORD
```

This release is suitable for direct local installation/testing. It is not a
Play Store release and does not establish Play App Signing custody.

The APK supports Android 6.0+ (`minSdk 23`) with Java time desugaring enabled
for older emulator images.

Important upgrade note: V2.12 uses the same local V2.9 release-key line, so it
can install over V2.9, V2.10, V2.11, and later same-key releases. Android
cannot install V2.12 over V2.8 or older releases signed with a different
certificate, or over debug builds. In that case, uninstall Wacken Planner first,
then install the V2.12 release APK and sync from Supabase.

## Known Non-Goals

- No Play Store distribution in V2.12.
- No shared synced manual schedule choices in V2.12; manual selections are
  local visible overrides only.
- No multiple independent groups in the current version.
- No self-service invite-token lifecycle or deep-link join flow.
- No user-configurable travel/lunch/food behavior.
- No PDF export.

## Accepted Risks

- Installed-device UAT still needs to be run on a connected Android device or
  emulator using the MVP2 UAT checklist.
- The V2.12 APK is signed with a local self-signed release key for direct
  installation/testing, not with Play App Signing.
- Installing over V2.8 or any older release/debug APK may fail by Android
  design due to signing-certificate mismatch. Uninstall the previous app first.
- BlueStacks must run an Android 6.0+ image for this APK.
