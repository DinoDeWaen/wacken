# Wacken Planner 2026 V2.11

Release date: 2026-06-12

## Scope

V2.11 is the official non-debug Android release APK for schedule conflict
scratch-rule corrections. It includes all V2.10 capabilities plus:

- Middle acts in chained visible overlaps are now barred when they lose to a
  higher-rated later overlap, even if they also beat a lower-rated earlier
  overlap.
- Schedule blocks now include walking pressure in barred-block decisions. A
  lower-rated visible block is barred when raw overlap plus walking time beyond
  the nearby-stage 5-minute allowance exceeds 15 minutes.
- A 15-minute raw overlap with a 15-minute cross-group walk is barred.
- A 15-minute raw overlap with only a 5-minute nearby-stage walk remains
  acceptable.

## Signing

The V2.11 GitHub release asset is built from the Android `release` variant and
signed with the same local self-signed V2.9 release-key line documented in
`backlog/docs/release-process.md`. The keystore and passwords are not committed
to git. Release signing is configured through local Gradle properties,
environment variables, or the local macOS keychain entries:

```text
WACKEN_RELEASE_STORE_FILE
WACKEN_RELEASE_STORE_PASSWORD
WACKEN_RELEASE_KEY_ALIAS
WACKEN_RELEASE_KEY_PASSWORD
```

This release is suitable for direct local installation/testing. It is not a
Play Store release and does not establish Play App Signing custody.

The APK supports Android 6.0+ (`minSdk 23`) with Java time desugaring enabled
for older emulator images.

Important upgrade note: V2.11 uses the same local V2.9 release-key line, so it
can install over V2.9, V2.10, and later same-key releases. Android cannot
install V2.11 over V2.8 or older releases signed with a different certificate,
or over debug builds. In that case, uninstall Wacken Planner first, then install
the V2.11 release APK and sync from Supabase.

## Validation

Automated validation for V2.11:

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew :domain:test :application:test :infrastructure:test :app:testDebugUnitTest :app:compileDebugJavaWithJavac assembleRelease

git diff --check
```

## Known Non-Goals

- No Play Store distribution in V2.11.
- No shared synced manual schedule choices in V2.11; manual selections are
  local visible overrides only.
- No multiple independent groups in the current version.
- No self-service invite-token lifecycle or deep-link join flow.
- No user-configurable travel/lunch/food behavior.
- No PDF export.

## Accepted Risks

- Installed-device UAT still needs to be run on a connected Android device or
  emulator using the MVP2 UAT checklist.
- The V2.11 APK is signed with a local self-signed release key for direct
  installation/testing, not with Play App Signing.
- Installing over V2.8 or any older release/debug APK may fail by Android
  design due to signing-certificate mismatch. Uninstall the previous app first.
- BlueStacks must run an Android 6.0+ image for this APK.
