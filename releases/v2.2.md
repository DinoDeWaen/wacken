# Wacken Planner 2026 V2.2

Release date: 2026-06-10

## Scope

V2.2 is the official non-debug Android release APK for schedule UI polish,
late-night festival-day handling, and walking-time visibility. It includes all
V2.1 capabilities plus:

- Schedule day headers with weekday names.
- Calendar schedule days that continue through 02:00 before the next festival
  day starts.
- Dark Wacken/metal styled schedule decision details instead of a default white
  dialog.
- Stronger heavy-metal startup and sync feedback.
- MVP walking-time defaults:
  - Heavy to Louder: 5 minutes.
  - Heavy or Louder to any other stage: 15 minutes.
  - Any two other stages: 5 minutes.
- Walking time shown between consecutive selected schedule acts where known.

## APK

```text
app/build/outputs/apk/release/app-release.apk
```

Build command:

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew assembleRelease
```

Android version metadata:

```text
versionCode 5
versionName 2.2
minSdk 23
```

## Signing

The V2.2 GitHub release asset is built from the Android `release` variant and
signed with a locally generated self-signed release keystore. The keystore and
passwords are not committed to git. Release signing is configured through local
Gradle properties or environment variables:

```text
WACKEN_RELEASE_STORE_FILE
WACKEN_RELEASE_STORE_PASSWORD
WACKEN_RELEASE_KEY_ALIAS
WACKEN_RELEASE_KEY_PASSWORD
```

This release is suitable for direct local installation/testing. It is not a
Play Store release and does not establish Play App Signing custody.

The APK supports Android 6.0+ (`minSdk 23`) with Java time desugaring enabled
for older emulator images.

Important upgrade note: Android cannot install this official release APK over a
previous debug APK with the same package name, because the signing certificates
do not match. If a debug build is already installed on BlueStacks or a device,
uninstall Wacken Planner first, then install the V2.2 release APK and sync from
Supabase.

apksigner verify --verbose app/build/outputs/apk/release/app-release.apk

## Known Non-Goals

- No Play Store distribution in V2.2.
- No shared synced manual schedule choices in V2.2; manual selections are local
  visible overrides only.
- No multiple independent groups in the current version.
- No self-service invite-token lifecycle or deep-link join flow.
- No user-configurable travel/lunch/food behavior.
- No PDF export.

## Accepted Risks

- Installed-device UAT still needs to be run on a connected Android device or
  emulator using the MVP2 UAT checklist.
- The V2.2 APK is signed with a local self-signed release key for direct
  installation/testing, not with Play App Signing.
- Installing over a previously installed debug APK fails by Android design due
  to signing-certificate mismatch. Uninstall the debug app first.
- BlueStacks must run an Android 6.0+ image for this APK.
