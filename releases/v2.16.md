# Wacken Planner 2026 V2.16

## Scope

V2.16 is an official non-debug Android release APK for the band-detail rating
reset label improvement.

Changes:

- The band detail clear-rating button now shows `Reset` instead of `0`.
- The reset action still clears the current user's rating to unrated value `0`.

## APK

```text
app/build/outputs/apk/release/app-release.apk
```
