# Wacken Planner 2026 V2.15

## Scope

V2.15 is an official non-debug Android release APK for the group-rating label
privacy/readability defect fix.

Changes:

- Band overview group-rating labels no longer show raw Supabase UUIDs.
- Band detail group-rating labels use the same compact readable labels.
- Known Sofie and Dino user IDs render as `S` and `D`; unknown UUID-like
  identities render as `U`.
- Stored rating identities are unchanged, so sync and ownership logic continue
  to use stable Supabase IDs.


## Signing

V2.15 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

## Install / Upgrade Guidance

V2.15 should install over V2.9 and later APKs signed with the same stable local
release key. Devices still running V2.8 or older releases signed with the
missing temporary key must uninstall once, install V2.15, sign in, and sync from
Supabase.

## Known Non-Goals

- No Play Store distribution in V2.15.
- No Supabase profile-display-name join in this release; group rating labels are
  compact app-side display labels.

## Accepted Risks

- Unknown UUID-like group members display as `U` until a profile-display-name
  lookup is added.
