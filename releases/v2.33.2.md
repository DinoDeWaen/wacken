# Wacken Planner 2026 V2.33.2

## Scope

This signed Android update delivers TASK-192 and TASK-193 in Release 2.33:

- **Discard pending** in the blocked-rating popup opens a second confirmation
  showing the band, stars, and stored festival ID. Confirming removes only that
  unchanged unsynced rating and retries sync. **Keep pending** and **Move to
  Wacken 2026** remain available.
- **Delete** on the active festival and **Delete festival** in an archived
  festival remove the selected festival for the group after confirmation. Its
  lineup, planning ratings, performances, and schedule decisions are removed.
  Central bands, other festivals, and personal rating history remain.
- Performances and schedule decisions now belong to a festival. Room migration
  8-to-9 and Supabase Flyway V011 assign legacy schedule data to Wacken 2026.
  Personal history retains the deleted festival's name, value, and date.
- Deleted Wacken data is not seeded again. Other devices clean the same
  festival after successful sync.

## Install and use

Install the attached `app-release.apk` over V2.33.1 to keep app data and pending
changes. Both versions use the same stable release certificate. Do not uninstall
or clear Android storage while a rating is pending.

To discard the blocked rating, sync, review the popup, choose **Discard
pending**, then confirm **Discard rating**. The action cannot be undone.

Festival deletion requires a connection and group membership. Review its
confirmation before continuing: festival planning ratings are deleted too.
Personal rating events and the central band catalog survive. Update all group
devices to V2.33.2 because the schedule-lock API now includes festival identity.

## Limits and accepted risks

Confirmed deletion and pending-rating discard are irreversible. There is no
undo or offline deletion queue. The affected phone was not attached for testing.
Older installations signed with the historical missing release key cannot use
an in-place update with the current stable key; V2.33 and V2.33.1 on the stable
key line can update normally.

The existing Supabase security-advisor findings for legacy functions and Flyway
metadata remain outside this hotfix. The new history trigger uses
`SECURITY INVOKER` and a fixed search path. See TASK-193 for advisory links and
the complete validation package, and ADR 0013 for the approved design.
