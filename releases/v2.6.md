# Wacken Planner 2026 V2.6

Release date: 2026-06-10

## Scope

V2.6 is the official non-debug Android release APK for the Dino Metal splash
screen update. It includes all V2.5 capabilities plus:

- The sync/startup splash now uses the provided Dino Metal artwork as a
  full-screen image backdrop.
- The previous generated heavy-metal backdrop has been removed from the sync
  overlay.
- The sync spinner and status message remain visible in a compact translucent
  top strip so the artwork stays dominant.

## APK

Release APK artifact:

```text
app/build/outputs/apk/release/app-release.apk
```

Build command:

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew assembleRelease
```

Android version metadata:

```text
versionCode 9
versionName 2.6
minSdk 23
```

## Signing

The V2.6 GitHub release asset is built from the Android `release` variant and
signed with the same locally generated self-signed V2.5 release key used for
V2.5. The keystore and passwords are not committed to git. Release signing is
configured through local Gradle properties or environment variables:

```text
WACKEN_RELEASE_STORE_FILE
WACKEN_RELEASE_STORE_PASSWORD
WACKEN_RELEASE_KEY_ALIAS
WACKEN_RELEASE_KEY_PASSWORD
```

This release is suitable for direct local installation/testing. It is not a
Play Store release and does not establish Play App Signing custody.

The APK supports Android 6.0+ (`minSdk 23`) with Java time desugaring enabled
for older emulator images.

Important upgrade note: V2.6 can install over V2.5 because it uses the same
local V2.5 release key. Android cannot install V2.6 over V2.4 or older builds
with the same package name but a different signing certificate. If V2.4 or any
debug build is installed on BlueStacks or a device, uninstall Wacken Planner
first, then install the V2.6 release APK and sync from Supabase.

## Known Non-Goals

- No Play Store distribution in V2.6.
- No shared synced manual schedule choices in V2.6; manual selections are local
  visible overrides only.
- No multiple independent groups in the current version.
- No self-service invite-token lifecycle or deep-link join flow.
- No user-configurable travel/lunch/food behavior.
- No PDF export.

## Accepted Risks

- Installed-device UAT still needs to be run on a connected Android device or
  emulator using the MVP2 UAT checklist.
- The V2.6 APK is signed with the local self-signed V2.5 release key for direct
  installation/testing, not with Play App Signing.
- Installing over V2.4, older releases, or debug APKs fails by Android design
  due to signing-certificate mismatch. Uninstall the previous app first.
- BlueStacks must run an Android 6.0+ image for this APK.
