# Wacken Planner 2026 V2.29

## Scope

V2.29 is an official signed Android maintenance release for the latest
workspace state after V2.28.

Changes since V2.28:

- Adds a Summer Breeze 2027 band-only import CSV under
  `data/summer-breeze-2027/bands.csv`.
- Records the Summer Breeze source page, row count, and source-data notes in
  `data/summer-breeze-2027/SOURCE.md`.
- Includes backlog planning records for future post-Wacken enhancements.
- Bumps Android release metadata to `versionCode 32` and `versionName 2.29`.

No app behavior, Supabase schema, persistence model, or schedule logic changed
in this release.

## Signing And Installation

V2.29 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

Install it over a release that uses the same stable signing key. Devices still
using an APK signed before the stable key was introduced must uninstall the old
app once, install V2.29, and then sync from Supabase. Future releases signed by
this key will update normally.

## Known Non-Goals

- No Play Store distribution in V2.29.
- No new app behavior in V2.29.
- No Supabase schema change in V2.29.
- No Summer Breeze stages, performances, distances, or food import data in
  V2.29.
- No fuzzy band linking or alias storage in V2.29.

## Accepted Risks

- The Summer Breeze 2027 lineup may change after this release; regenerate the
  CSV before using it as final festival data.
- The Summer Breeze import is band-only, so the app should show imported bands
  as unscheduled until performance CSV data exists.
- Devices still using an APK signed before the stable key was introduced must
  uninstall once before installing V2.29.
