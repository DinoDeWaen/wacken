# Wacken Planner 2026 V2.21

## Scope

V2.21 is the official signed Android release for the completed MVP3 field-use
scope.

Changes since V2.20:

- Supabase Auth session refresh now preserves the local session when Supabase
  cannot be reached because the device is offline, so cached data remains
  usable without forcing a login.
- Band detail includes a separate local real post-show rating on the same
  visible 1-5 scale, with reset-to-unrated behavior and no impact on planning
  ratings or schedule decisions.
- Settings can export all locally cached rating data to CSV through Android
  share/save targets, including planning ratings, real post-show ratings,
  cached group member ratings, and schedule metadata where known.
- MVP3 no-Wi-Fi field mode was validated across cached startup, band detail,
  settings export, generated schedule viewing, planning-rating edits,
  real-rating edits, and manual schedule-lock edits.

## Signing And Installation

V2.21 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

Install it over a release that uses the same stable signing key. Devices still
using an APK signed before the stable key was introduced must uninstall the old
app once, install V2.21, and then sync from Supabase. Future releases signed by
this key will update normally.

## Manual MVP3 Smoke Evidence

The release task records the manual MVP3 smoke checklist for:

- CSV export from settings using locally cached data.
- Real post-show rating and reset behavior on band detail.
- No-Wi-Fi cached startup, details, schedule, and local offline edits after
  data has already been synced or imported.

## Known Non-Goals

- No Play Store distribution in V2.21.
- No MVP4 capabilities are part of this release.
- No shared Supabase sync for real post-show ratings is part of this release.
- No multiple-group support is part of this release.

## Accepted Risks

- Physical no-Wi-Fi and Android share-sheet smoke tests are documented in the
  release task but were not executed from this workspace.
- First install without previously synced or imported festival data still
  requires an initial Supabase sync or CSV import.
