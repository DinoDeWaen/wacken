# Wacken Planner 2026 V2.5

Release date: 2026-06-10

## Scope

V2.5 is the official non-debug Android release APK for the schedule
alternatives defect fix. It includes all V2.4 capabilities plus:

- Schedule decision details only show alternatives that directly overlap the
  selected act's own performance time.
- Indirectly chained conflicts no longer create very long alternatives lists
  for acts such as Def Leppard.
- Lost-alternative metadata follows the same direct-overlap rule.
- Walking-time context in the decision detail is limited to the visible
  candidates for that same detail.

## APK

Release APK artifact:

```text
app/build/outputs/apk/release/app-release.apk
```

Build command:

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew assembleRelease
```

Android version metadata:

```text
versionCode 8
versionName 2.5
minSdk 23
```

## Signing

The V2.5 GitHub release asset is built from the Android `release` variant and
signed with a locally generated self-signed release keystore. The V2.1-V2.4
release keystore was present locally but its passwords were not available in
the release shell, so V2.5 uses a newly generated local self-signed V2.5
release key. The keystore and passwords are not committed to git. Release
signing is configured through local Gradle properties or environment variables:

```text
WACKEN_RELEASE_STORE_FILE
WACKEN_RELEASE_STORE_PASSWORD
WACKEN_RELEASE_KEY_ALIAS
WACKEN_RELEASE_KEY_PASSWORD
```

This release is suitable for direct local installation/testing. It is not a
Play Store release and does not establish Play App Signing custody.

The APK supports Android 6.0+ (`minSdk 23`) with Java time desugaring enabled
for older emulator images.

Important upgrade note: Android cannot install this official release APK over a
previous APK with the same package name but a different signing certificate. If
V2.4 or any older build is already installed on BlueStacks or a device,
uninstall Wacken Planner first, then install the V2.5 release APK and sync from
Supabase.

## Validation

Automated validation for V2.5:

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew :domain:test :application:test :infrastructure:test :app:testDebugUnitTest :app:compileDebugJavaWithJavac assembleRelease
apksigner verify --verbose app/build/outputs/apk/release/app-release.apk
git diff --check
```

## Known Non-Goals

- No Play Store distribution in V2.5.
- No shared synced manual schedule choices in V2.5; manual selections are local
  visible overrides only.
- No multiple independent groups in the current version.
- No self-service invite-token lifecycle or deep-link join flow.
- No user-configurable travel/lunch/food behavior.
- No PDF export.

## Accepted Risks

- Installed-device UAT still needs to be run on a connected Android device or
  emulator using the MVP2 UAT checklist.
- The V2.5 APK is signed with a new local self-signed V2.5 release key for
  direct installation/testing, not with Play App Signing.
- Installing over a previously installed V2.4 or debug APK fails by Android
  design due to signing-certificate mismatch. Uninstall the previous app first.
- BlueStacks must run an Android 6.0+ image for this APK.
