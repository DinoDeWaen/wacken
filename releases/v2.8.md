# Wacken Planner 2026 V2.8

Release date: 2026-06-11

## Scope

V2.8 is the official non-debug Android release APK for Settings rating
allocation counts and refined sync visuals. It includes all V2.7 capabilities
plus:

- Settings shows the signed-in user's rating allocation counts for 5, 4, 3, 2,
  and 1 stars.
- Rating allocation counts include zero-count buckets so every rating value is
  visible.
- The full Dino Metal splash is limited to the initial startup sync.
- Later syncs keep the current screen visible and show compact moving sync
  feedback instead of the full-screen splash.
- Settings manual sync shows a lightweight rotating sync indicator over the
  current Settings screen.

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew assembleRelease

```

## Signing

The V2.8 GitHub release asset is built from the Android `release` variant and
signed with the same locally generated self-signed V2.5 release key used for
V2.5, V2.6, and V2.7. The keystore and passwords are not committed to git.
Release signing is configured through local Gradle properties or environment
variables:

```text
WACKEN_RELEASE_STORE_FILE
WACKEN_RELEASE_STORE_PASSWORD
WACKEN_RELEASE_KEY_ALIAS
WACKEN_RELEASE_KEY_PASSWORD
```

This release is suitable for direct local installation/testing. It is not a
Play Store release and does not establish Play App Signing custody.

The APK supports Android 6.0+ (`minSdk 23`) with Java time desugaring enabled
for older emulator images.

Important upgrade note: V2.8 can install over V2.5, V2.6, and V2.7 because it
uses the same local V2.5 release key. Android cannot install V2.8 over V2.4 or
older builds with the same package name but a different signing certificate. If
V2.4 or any debug build is installed on BlueStacks or a device, uninstall
Wacken Planner first, then install the V2.8 release APK and sync from Supabase.

## Known Non-Goals

- No Play Store distribution in V2.8.
- No shared synced manual schedule choices in V2.8; manual selections are local
  visible overrides only.
- No multiple independent groups in the current version.
- No self-service invite-token lifecycle or deep-link join flow.
- No user-configurable travel/lunch/food behavior.
- No PDF export.

## Accepted Risks

- Installed-device UAT still needs to be run on a connected Android device or
  emulator using the MVP2 UAT checklist.
- The V2.8 APK is signed with the local self-signed V2.5 release key for direct
  installation/testing, not with Play App Signing.
- Installing over V2.4, older releases, or debug APKs fails by Android design
  due to signing-certificate mismatch. Uninstall the previous app first.
- BlueStacks must run an Android 6.0+ image for this APK.
