# Wacken Planner 2026 V2.19

## Scope

V2.19 is the official signed Android release for the completed professional
metal UX refinements.

Changes since V2.18:

- The band detail screen separates rating, running-order, and links content,
  shows group-member ratings beneath the user's own rating, and uses a clear
  `Reset` action for an unrated band.
- The group schedule has an optional compact key that explains its rating,
  lock, tie, conflict, and filter states. Filter labels now state precisely
  what they hide.
- Settings and import flows provide explicit sync, pending-change, success,
  failure, and next-action feedback while preserving offline cached use.
- Shared ratings, group locks, and offline changes continue to use the existing
  Room-first, queued-sync workflow.

## Signing And Installation

V2.19 uses the stable local V2.9+ release-key line managed by
`scripts/ensure-release-keystore.sh`.

Install it over a release that uses the same stable signing key. Devices still
using an APK signed before the stable key was introduced must uninstall the old
app once, install V2.19, and then sync from Supabase. Future releases signed by
this key will update normally.

## Known Non-Goals

- No Play Store distribution in V2.19.
- No schema change or additional backend capability is part of this release.
- `task-117` remains open to apply and verify the optional group-schedule-lock
  backend schema; the app continues to fall back safely when that remote table
  is unavailable.
